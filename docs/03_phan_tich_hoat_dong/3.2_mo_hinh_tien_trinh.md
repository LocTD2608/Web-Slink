# 3.2 Mô Hình Tiến Trình & Xử Lý Bất Đồng Bộ (Async I/O Event Loop)

## 1. Mô Hình Asynchronous Event Loop (FastAPI / Uvicorn)
Hệ thống sử dụng Python 3.12 kết hợp **Uvicorn** và **AsyncIO** để vận hành theo mô hình Non-blocking Single-threaded Event Loop trên mỗi worker process:
* **Cơ chế xử lý:** Khi một request chờ I/O mạng (như đợi Redis trả về kết quả Lua script hoặc đợi RabbitMQ nhận publish), Event Loop tự động chuyển ngữ cảnh để phục vụ hàng trăm request khác đang chờ.
* **Ngăn chặn Head-of-line Blocking:**
  1. Loại bỏ toàn bộ các thao tác đồng bộ khóa luồng (Synchronous I/O). Sử dụng 100% async drivers: `redis.asyncio`, `aio-pika`, `asyncpg`.
  2. Các tác vụ nặng về tính toán (như hash mật khẩu Bcrypt) bị loại bỏ khỏi luồng ghi danh cao điểm; xác thực JWT chỉ giải mã HMAC-SHA256 trong bộ nhớ.

## 2. Mô Hình Đa Tiến Trình (Multi-Process Concurrency)
* Mỗi FastAPI Node chạy với 2 đến 4 Uvicorn Workers độc lập được quản lý bởi Process Manager.
* Với 2 nodes (tổng 4-8 workers), hệ thống có khả năng giữ đồng thời hơn 10.000 socket connections mở mà không bị nghẽn CPU.
