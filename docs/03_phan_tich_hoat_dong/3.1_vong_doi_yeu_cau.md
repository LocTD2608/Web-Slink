# 3.1 Vòng Đời Yêu Cầu (Request Lifecycle: Client -> Proxy -> App -> Queue -> DB)

## 1. Chi Tiết Vòng Đời Yêu Cầu Đăng Ký Học Phần (Write Path)

```
[1. Sinh viên nhấn "Đăng ký"]
       │
       ▼ (HTTPS POST kèm X-Idempotency-Key + Bearer Token)
[2. Nginx Reverse Proxy]
       │ ── Kiểm tra Rate Limiting (Token Bucket: 15 req/s/IP)
       │ ── Phân tải Round-Robin
       ▼
[3. FastAPI Backend Instance]
       │ ── In-Memory Auth Middleware: Xác thực JWT HMAC-SHA256 (O(1) CPU, không query DB)
       │ ── Idempotency Middleware: Redis SET idempotency:{key} "PROCESSING" EX 60 NX
       │    └── Nếu đã tồn tại -> Trả HTTP 409 Conflict (Chặn trùng lặp / spam click)
       ▼
[4. Redis Atomic Lua Engine]
       │ ── Bước A: Kiểm tra sinh viên đã giữ slot lớp này chưa (SISMEMBER)
       │ ── Bước B: Kiểm tra môn tiên quyết (SISMEMBER student:completed_courses)
       │ ── Bước C: Kiểm tra trùng lịch học (BITOP AND mặt nạ 84-bit thời gian)
       │ ── Bước D: Kiểm tra hạn mức tín chỉ (current_credits + credits <= max_credits)
       │ ── Bước E: Trừ slot khả dụng (DECR section:{id}:slots) & lưu student_id (SADD)
       │
       ├──► NẾU THẤT BẠI: Trả về mã lỗi chi tiết ngay tức thì (< 5ms, không chạm DB)
       ▼
       └──► NẾU THÀNH CÔNG: Slot đã giữ chỗ (RESERVED)
[5. Trả về Client & Đẩy Hàng Đợi]
       │ ── Trả về HTTP 202 Accepted: {"ticket_id": "...", "status": "PENDING"} (< 50ms)
       │ ── Đẩy message vào RabbitMQ `registration_queue`
       ▼
[6. Background Registration Worker]
       │ ── Tiêu thụ message từ RabbitMQ (Rate-matched 200-300 records/s)
       │ ── Mở Transaction ghi vào PostgreSQL: INSERT INTO registrations...
       │
       ├──► THÀNH CÔNG: Cập nhật Redis `ticket:{id}:status = "CONFIRMED"`
       ▼
       └──► THẤT BẠI (Sau 3 lần Retry):
            Kích hoạt Compensating Rollback trên Redis (INCR slot, SREM student, hoàn trả tín chỉ)
            Cập nhật Redis `ticket:{id}:status = "FAILED"`, đẩy message vào Dead-Letter Queue (DLQ)
[7. Frontend Controlled Short Polling]
       │ ── Thăm dò GET /api/v1/registrations/status/{ticket_id} mỗi 1.0s (tối đa 3 lần)
       │ ── Đọc trực tiếp từ Redis key ticket:{id}:status (< 1ms)
       ▼
[8. Hiển thị thông báo Thành công / Thất bại trên giao diện sinh viên]
```
