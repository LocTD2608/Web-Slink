# 2.3 Giải Pháp Mở Rộng Hệ Thống (Shared-Nothing Horizontal Scaling & Load Balancing)

## 1. Nguyên Lý Shared-Nothing Trong Tầng Ứng Dụng (App Server Layer)
Tầng máy chủ ứng dụng Backend (FastAPI) được thiết kế theo triết lý **Stateless (Phi trạng thái)**:
1. **Không lưu trữ Session/State trong bộ nhớ cục bộ (Local Memory):**
   * Thông tin định danh sinh viên được giải mã từ JWT token đối xứng (HMAC-SHA256).
   * Mọi trạng thái chia sẻ (Shared State) như số slot còn lại, danh sách sinh viên đã giữ chỗ, mặt nạ thời khóa biểu đều nằm tập trung tại **Redis**.
2. **Khả năng Mở rộng Tuyến tính (Horizontal Scaling):**
   * Có thể bổ sung thêm bất kỳ số lượng FastAPI Node nào (`fastapi-node-3`, `node-4`, ...) vào cụm Nginx Upstream mà không ảnh hưởng đến tính nhất quán của dữ liệu.
   * Nginx tự động phân bổ tải theo thuật toán **Round-Robin** hoặc **Least Connections**.

---

## 2. Cân Bằng Tải L7 Tại Tầng Biên (Nginx Reverse Proxy)
* **Keep-Alive Pool:** Duy trì kết nối TCP mở sẵn giữa Nginx và FastAPI Nodes (`keepalive 32`), loại bỏ chi phí bắt tay TCP 3 bước (Three-way Handshake) cho mỗi request HTTP.
* **Upstream Health Check:** Tự động cô lập các node ứng dụng bị lỗi thông qua cơ chế `max_fails=3 fail_timeout=10s`.
* **SSL/TLS Termination:** Giải mã HTTPS trực tiếp tại Nginx để giảm tải chu kỳ CPU cho các tiến trình Python Backend.
