# 2.1 Sơ Đồ Tổng Thể Hạ Tầng (Network Topology & Security Zones)

## 1. Mô Hình Phân Vùng Mạng Nội Bộ (VPC & Subnet Architecture)

Hệ thống được thiết kế theo mô hình mạng phân vùng bảo mật 3 lớp (3-Tier DMZ/VPC Topology):

```
                                  [ INTERNET ]
                                       │
                                       ▼ (HTTPS 443)
      ╔═══════════════════════════════════════════════════════════════════════╗
      ║                     PUBLIC SUBNET (DMZ VÙNG BIÊN)                     ║
      ║                                                                       ║
      ║   [Nginx Reverse Proxy & Load Balancer] (Port 80/443)                ║
      ║     ├── SSL Termination / TLS 1.3 Offloading                          ║
      ║     ├── Token Bucket Rate Limiting (15 req/s/IP)                      ║
      ║     ├── Gzip Compression (Static & JSON)                              ║
      ║     └── Round-Robin Upstream Load Balancing                           ║
      ╚══════════════════════════════════╤════════════════════════════════════╝
                                         │ Internal HTTP (Port 8000/8001)
      ╔══════════════════════════════════▼════════════════════════════════════╗
      ║                  APPLICATION SUBNET (VÙNG ỨNG DỤNG)                   ║
      ║                                                                       ║
      ║   [FastAPI Node 1] ◄────────┐  [FastAPI Node 2] ◄────────┐            ║
      ║   (Uvicorn Workers)         │  (Uvicorn Workers)         │            ║
      ║         │                   │        │                   │            ║
      ║         ▼                   │        ▼                   │            ║
      ║   [Redis In-Memory] ────────┘  [RabbitMQ Message Broker] ─┘           ║
      ║   ├── Atomic Lua CAS Engine    ├── Registration Queue                 ║
      ║   ├── Pre-warmed Catalog Cache └── Dead-Letter Queue (DLQ)            ║
      ║   └── Ticket Status Store                                             ║
      ╚══════════════════════════════════╤════════════════════════════════════╝
                                         │ TCP (AMQP & Port 5432)
      ╔══════════════════════════════════▼════════════════════════════════════╗
      ║                 DATA / PERSISTENCE SUBNET (VÙNG CSDL)                 ║
      ║                                                                       ║
      ║   [Registration Worker Consumer] (Rate-matched 250 records/s)         ║
      ║         │                                                             ║
      ║         ▼ (Async Connection Pool / PgBouncer)                         ║
```

## 2. Nguyên Tắc Phân Vùng An Toàn Thông Tin
1. **DMZ (Public Subnet):** Chỉ có Nginx Reverse Proxy được cấp IP tĩnh công khai (Public IP).
2. **Application Subnet:** Các máy chủ FastAPI, Redis và RabbitMQ nằm hoàn toàn trong mạng Private Subnet, chỉ chấp nhận kết nối từ IP của Nginx.
3. **Data Subnet:** CSDL PostgreSQL tuyệt đối không mở port ra Internet; chỉ cho phép các kết nối từ Registration Worker và App Container nội bộ VPC thông qua Security Groups chặt chẽ.
