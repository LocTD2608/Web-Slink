# 2.2 Định Mức Cấu Hình Máy Chủ & Tài Nguyên Phần Cứng

## 1. Bảng Định Mức Máy Chủ Môi Trường Sản Xuất (Production Sizing - 3.000 CCU)

| Phân tầng dịch vụ | Số lượng Nodes | CPU Cores | Dung lượng RAM | Ổ đĩa lưu trữ | Băng thông mạng |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Web Server (Nginx)** | 2 Nodes (HA) | 2 vCPU | 4 GB RAM | 50 GB SSD | 1 Gbps NIC |
| **App Server (FastAPI)**| 3 Nodes | 4 vCPU | 4 GB RAM | 50 GB SSD | 10 Gbps VPC |
| **In-Memory (Redis)** | 1 Master + 1 Replica | 4 vCPU | 8 GB RAM | 100 GB SSD NVMe | 10 Gbps VPC |
| **Message Broker (RabbitMQ)**| 2 Nodes | 2 vCPU | 4 GB RAM | 100 GB SSD | 10 Gbps VPC |
| **Database (PostgreSQL)**| 1 Primary + 1 Standby | 8 vCPU | 16 GB RAM | 250 GB NVMe (5.000 IOPS)| 10 Gbps VPC |
| **Worker Cluster** | 2 Nodes | 2 vCPU | 4 GB RAM | 50 GB SSD | 10 Gbps VPC |

## 2. Bảng Cấu Hình Tối Ưu Cho Môi Trường Demo Thực Tế (Local PC 16GB RAM)

Để phục vụ trình diễn trọn vẹn và an toàn trên một máy tính cá nhân (16GB RAM), toàn bộ các dịch vụ được đóng gói bằng **Docker Compose** với mức giới hạn tài nguyên (Resource Limits) tinh gọn như sau:

| Container | CPU Limit | RAM Limit | RAM Tiêu thụ Thực tế (Peak) | Ghi chú |
| :--- | :--- | :--- | :--- | :--- |
| `nginx` | 0.5 Core | 256 MB | ~50 MB | Reverse Proxy, Rate Limit 15 req/s |
| `fastapi-node-1`| 1.0 Core | 512 MB | ~180 MB | Async Uvicorn Worker |
| `fastapi-node-2`| 1.0 Core | 512 MB | ~180 MB | Async Uvicorn Worker |
| `redis` | 1.0 Core | 512 MB | ~120 MB | Lua Scripts, Pre-warm Cache |
| `rabbitmq` | 1.0 Core | 512 MB | ~280 MB | Queue Buffer |
| `postgres` | 2.0 Core | 1.024 MB (1GB) | ~400 MB | Relational System of Record |
| `worker` | 1.0 Core | 512 MB | ~150 MB | Persist to DB & Compensating Rollback |
| **TỔNG CỘNG** | **7.5 Cores**| **3.840 MB (~3.8 GB)**| **~1.380 MB (~1.4 GB)** | **Vận hành cực êm ái trên PC 16GB RAM** |
