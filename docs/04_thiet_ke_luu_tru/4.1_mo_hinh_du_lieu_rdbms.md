# 4.1 Thiết Kế Mô Hình Dữ Liệu RDBMS (PostgreSQL Schema & Index Optimization)

## 1. Lược Đồ Bảng Cơ Sở Dữ Liệu

```sql
-- 1. Bảng Sinh viên (students)
CREATE TABLE students (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    student_code VARCHAR(20) UNIQUE NOT NULL,
    full_name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    major VARCHAR(50) NOT NULL,
    academic_year INT NOT NULL,
    max_credits INT DEFAULT 24 NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Bảng Môn học (courses)
CREATE TABLE courses (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    course_code VARCHAR(20) UNIQUE NOT NULL,
    course_name VARCHAR(150) NOT NULL,
    credits INT NOT NULL,
    prerequisite_course_id UUID REFERENCES courses(id),
    department VARCHAR(50) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 3. Bảng Học kỳ (semesters)
CREATE TABLE semesters (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    semester_code VARCHAR(20) UNIQUE NOT NULL,
    name VARCHAR(50) NOT NULL,
    is_active BOOLEAN DEFAULT FALSE,
    start_date DATE NOT NULL,
    end_date DATE NOT NULL
);

-- 4. Bảng Lớp học phần (course_sections)
CREATE TABLE course_sections (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    section_code VARCHAR(30) UNIQUE NOT NULL,
    course_id UUID NOT NULL REFERENCES courses(id),
    semester_id UUID NOT NULL REFERENCES semesters(id),
    instructor VARCHAR(100) NOT NULL,
    classroom VARCHAR(50) NOT NULL,
    schedule_day INT NOT NULL, -- 2: Thứ Hai ... 7: Thứ Bảy, 8: Chủ Nhật
    start_period INT NOT NULL, -- Tiết bắt đầu: 1 -> 12
    end_period INT NOT NULL,   -- Tiết kết thúc: 1 -> 12
    time_mask BIGINT NOT NULL, -- Mặt nạ 84-bit biểu diễn thời gian học
    max_capacity INT NOT NULL, -- Sĩ số tối đa (ví dụ 30 hoặc 50)
    current_enrolled INT DEFAULT 0 NOT NULL, -- Số lượng sinh viên đã ghi danh
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 5. Bảng Đăng ký học phần (registrations)
CREATE TABLE registrations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    ticket_id VARCHAR(64) UNIQUE NOT NULL,
    student_id UUID NOT NULL REFERENCES students(id),
    section_id UUID NOT NULL REFERENCES course_sections(id),
    semester_id UUID NOT NULL REFERENCES semesters(id),
    status VARCHAR(20) NOT NULL DEFAULT 'CONFIRMED', -- CONFIRMED, CANCELLED, FAILED
    registered_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    CONSTRAINT uq_student_section UNIQUE (student_id, section_id)
);
```

---

## 2. Chiến Lược Đánh Chỉ Mục (Index Optimization)
* `CREATE INDEX idx_sections_semester ON course_sections(semester_id);`: Tối ưu hóa truy vấn toàn bộ lớp học phần trong kỳ khi Warm-up Cache.
* `CREATE INDEX idx_registrations_student ON registrations(student_id);`: Tối ưu hóa truy cứu lịch sử và danh sách môn đã học của sinh viên.
* `CONSTRAINT uq_student_section`: Unique B-Tree Index bắt buộc nhằm đảm bảo tính toàn vẹn (Idempotency) ở tầng lưu trữ cuối cùng, ngăn chặn triệt để 1 sinh viên có 2 bản ghi cùng một lớp.
