# 5.2 Kiểm Soát Đồng Thời & Xử Lý Race Condition (Atomic Lua CAS)

## 1. Bài Toán Race Condition Khi Trừ Sĩ Số Lớp
Xét kịch bản cao điểm: Một lớp học phần chỉ còn **3 slot trống**, nhưng có **500 sinh viên** cùng bấm "Đăng ký" trong cùng 1 phần trăm giây ($10\text{ms}$).
* **Nếu dùng RDBMS SELECT ... UPDATE truyền thống:**
  Xảy ra tranh chấp khóa bi quan (Pessimistic Lock Deadlock) hoặc bán vượt sĩ số (Overselling) do hiện tượng Read-Modify-Write không nguyên tử.

---

## 2. Giải Pháp: Redis Atomic Lua Script (Compare-And-Swap - CAS)
Redis xử lý các lệnh theo mô hình đơn luồng (Single-threaded Execution Engine). Toàn bộ mã Lua Script được thực thi hoàn toàn nguyên tử (Atomic): không có bất kỳ lệnh nào khác xen vào giữa quá trình kiểm tra và trừ slot.

```lua
-- Lua Script trừ slot nguyên tử tích hợp thẩm định toàn diện
local section_id = KEYS[1]
local student_id = ARGV[1]
local prereq_course_id = ARGV[2]
local section_mask = tonumber(ARGV[3])
local section_credits = tonumber(ARGV[4])

-- 1. Kiểm tra xem sinh viên đã đăng ký lớp này chưa
if redis.call('SISMEMBER', 'section:' .. section_id .. ':enrolled', student_id) == 1 then
    return -1 -- ALREADY_ENROLLED
end

-- 2. Kiểm tra slot lớp học phần
local slots = tonumber(redis.call('GET', 'section:' .. section_id .. ':slots') or 0)
if slots <= 0 then
    return -2 -- SECTION_FULL
end

-- 3. Kiểm tra môn tiên quyết (nếu có)
if prereq_course_id ~= "" and prereq_course_id ~= "NONE" then
    if redis.call('SISMEMBER', 'student:' .. student_id .. ':completed_courses', prereq_course_id) == 0 then
        return -3 -- PREREQUISITE_NOT_MET
    end
end

-- 4. Kiểm tra trần tín chỉ
local current_credits = tonumber(redis.call('HGET', 'student:' .. student_id .. ':credits', 'current') or 0)
local max_credits = tonumber(redis.call('HGET', 'student:' .. student_id .. ':credits', 'max') or 24)
if current_credits + section_credits > max_credits then
    return -4 -- CREDIT_LIMIT_EXCEEDED
end

-- 5. Thực hiện trừ slot và cập nhật dữ liệu sinh viên
redis.call('DECR', 'section:' .. section_id .. ':slots')
redis.call('SADD', 'section:' .. section_id .. ':enrolled', student_id)
redis.call('HINCRBY', 'student:' .. student_id .. ':credits', 'current', section_credits)

return 1 -- SUCCESS
```

* **Kết quả:** Đảm bảo **chính xác 100%** không bao giờ có quá 30 người được ghi nhận vào lớp 30 chỗ (Zero Overselling).
